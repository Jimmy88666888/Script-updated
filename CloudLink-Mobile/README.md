# CloudLink Mobile

国际网盘 **手机直链助手** 油猴脚本：Google Drive / OneDrive(SharePoint) / Dropbox。

## 功能

- 右下角悬浮 **直链** 按钮
- 复制 **1DM+** / **ytdlnis** / 普通直链
- Google Drive：单文件直链（含 confirm 参数）、文件夹可见文件批量复制
- OneDrive / SharePoint：尝试解析 download 链
- Dropbox：分享链转 `dl=1` 直链

## 安装

https://raw.githubusercontent.com/Jimmy88666888/CloudLink-Mobile/main/CloudLink-Mobile.user.js

## 使用

打开网盘文件/分享页 → 点右下角 **直链** → 选择 **1DM+** 复制 → 到 1DM+ 从剪贴板添加。

## 说明

- 大文件 / 有权限限制 / 企业策略的文件可能无法得到可用直链
- Google Drive 病毒扫描提示页会尽量自动确认
- 不收集任何数据
